## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not include an executable utility.

### Does this repository include a working auto-clicker?

No. It explains auto-clicker terminology and Lineage 2 use cases but does not generate mouse input.

### Is it compatible with Windows 11?

The reference can be viewed on Windows 11 using a standard browser or Markdown viewer. It does not interact with the game client.

### What auto-clicker topics are covered?

The guide covers repeated clicking, input intervals, click patterns, macro terminology, and common Lineage 2 farming contexts.

### Are auto-clickers allowed in Lineage 2?

Rules depend on the game service and server. Some Lineage 2 agreements prohibit unauthorized software that automates gameplay, while individual private-server rules may explicitly prohibit external clickers and macros. Check the current rules for your server before using one.
